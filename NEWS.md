# peakAge 0.2.0 (2026-11-23)

- Added an opt-in extended asymmetric model with separate component formulas,
  competition-level score adjustments, correlated athlete effects, grouped
  peak-level SDs, and athlete-specific residual SDs with standardized two-piece
  Student-t errors.
- Extended posterior summaries and predictive plots to use the fitted model's
  observation and residual specifications.
- Added a full-cohort application example mapping the manuscript's component
  designs and both fixed prior profiles to the extended model.
- Added regression tests for component-specific designs, athlete indexing,
  competition adjustments, grouped scales, and prior validation.
